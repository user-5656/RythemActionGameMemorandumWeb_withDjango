音楽同期とは

音楽同期とは ---音ゲー制作において、音と譜面（描画）のタイミングを合わせることである。

Unity では、音源を制御する時間、画面の描画に関する時間の2つがある。これが意味することは、2つの時間をつなげなければならないということだ。

そのつなぐ手法について、こういった概念についてを前提として筆者は話を進めている。

音源の時間

Unity では、AudioSettings.dspTime という方法で時間を呼び出せる。

void Start() { 
    _audioDspStartTime = AudioSettings.dspTime + kStartScheduleBuffer;
    _musicSource.PlayScheduled(_audioDspStartTime);
}

kStartScheduleBuffer は、任意で時間を追加できるようにしたものである。

_musicSource.PlayScheduled(_audioDspStartTime); では、_musicSourceに入れた音楽ファイルを _audioDspStartTime の秒数だけ待って再生するという意味である。

つまり、音楽を再生するコードである。何ら不思議なことはない。

線形回帰は何か、なぜこの話に？

ゲームの時間と音源の時間を結びつけるために、線形回帰 を利用しようという話である。ここで注意。

void Update() {
    float currentGameTime = Time.realtimeSinceStartup;
    double currentDspTime = AudioSettings.dspTime;

    // 線形回帰モデルに別のデータポイントを追加して更新します。
    UpdateLinearRegression(currentGameTime, currentDspTime);
}

このコードは、このままでは、Unity 上で動かない。UpdateLinearRegression(currentGameTime, currentDspTime); とは何ぞやといわれる。絶望である。

UpdateLinearRegression(currentGameTime, currentDspTime); を用いるための手法を模索した。

今回私が一番紹介したいことだ。長い時間を費やすことなく、スムーズに次のステップにいく手助けになればと思う。

UpdateLinearRegression を用いるための手法は NuGet を導入し、MathNet.Numericsをダウンロードする。

導入手順:

  1. Unityを開き、上のメニューから 「Window」 ＞ 「Package Manager」
  2. 左上の「＋」ボタン ＞ 「Add package from git URL...」
  3. 以下のURLを貼り付けて「Add」をクリック
    https://github.com/GlitchEnzo/NuGetForUnity.git?path=/src/NuGetForUnity
  4. 「NuGet」 ＞ 「Manage NuGet Packages」 を開き、そこで MathNet.Numerics と System.Text.Json を検索してインストール。System.Text.Json のバージョンは、8.0.5にすること。（2026年8月現在）

そうして以下のように void Update()に入れる

double Ga = currentGameTime;
double Ds = currentDspTime;

Gdata.Add(Ga);
Ddata.Add(Ds);

if (Gdata.Count > 10 && Ddata.Count > 10)
{
    Gdata.RemoveAt(0);
    Ddata.RemoveAt(0);
}

if (Gdata.Count < 2 || Ddata.Count < 2) return;

p = Fit.Polynomial(Gdata.ToArray(), Ddata.ToArray(), 1);

これにより、線形回帰ができる。

※ しかし、デバイスによっては、重すぎて描画がカクカクになってしまうので、線形回帰する回数を数秒に1回などと決めることも大切である。
